CIET STATIC WEBSITE TEMPLATE

Files:
- index.html: website structure and content
- style.css: responsive design and layout
- script.js: mobile navigation and automatic footer year
- assets/ciet-logo.svg: editable placeholder CIET-style logo

HOW TO RUN:
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html to view the site in your browser.

CUSTOMIZE:
- Edit index.html to change the college name, department details, contact information, and text.
- Replace assets/ciet-logo.svg with your official logo (update the image path in index.html if needed).
- Edit style.css to change colors and appearance.
- No server or installation is required. Google Fonts load from the internet; system fonts are used if unavailable.

NOTE:
This is a sample static template and is not an official college website. Replace placeholder text and contact details before publishing.
